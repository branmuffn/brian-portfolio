# Brian Tea · Portfolio

My personal portfolio site, built during the Frontier Commons Build Bootcamp.

Live: https://brian-portfolio-amber.vercel.app

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing

All page text (projects, timeline, skills, contact) lives in `app/content.ts`.
Layout and styling are in `app/page.tsx` and `app/globals.css`.
